# LeetCode Çözümleri

[![LeetCode](https://img.shields.io/badge/LeetCode-FFA116?style=for-the-badge&logo=leetcode&logoColor=white)](https://leetcode.com/u/YQJCVT3fw6/)
[![Java](https://img.shields.io/badge/Java-ED8B00?style=for-the-badge&logo=openjdk&logoColor=white)](https://www.java.com)

Bu depo, LeetCode üzerindeki çözdüğüm algoritma ve veri yapısı sorularının çözümlerini içermektedir.  
Tüm çözümler **LeetHub v2** aracı kullanılarak otomatik olarak GitHub deposuna aktarılmaktadır.

---

## Amaç

Bu depo şu amaçlarla oluşturulmuştur:

- Algoritma ve veri yapıları konularında gelişimi takip etmek
- Teknik mülakatlara hazırlık yapmak
- Önceden çözülmüş soruları tekrar gözden geçirmek
- Düzenli pratik alışkanlığı oluşturmak


## Yapı

Her klasör ilgili LeetCode soru numarasını ve açıklamasını içerir.

Depodaki içerikler otomatik olarak oluşturulduğundan:
- Soru açıklaması (LeetHub tarafından eklenir)
- Çözüm dosyası (Java)
- LeetHub'ın oluşturduğu ek dosyalar

bulunabilir.

## Kullanılan Araçlar

Bu depo şu araç ve iş akışıyla yönetilmektedir:

- **LeetHub v2** Chrome eklentisi
- Kabul edilen çözümlerin otomatik GitHub'a aktarılması
- Düzenli ve gezilebilir klasör yapısı
- Tüm çözümler **Java** dilinde
